### dev

```bun run dev -> http://localhost:8000```

serves the site with live reload — edits to html/js reload the page, edits to
css swap in without one. no dependencies to install; `bunx` fetches
`live-server` on demand and caches it.

no bun? `python3 -m http.server` still works, just without the reload.
